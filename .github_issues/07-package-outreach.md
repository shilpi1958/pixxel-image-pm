## Why
The project only matters if the right person sees it, framed the right way.

## Tasks
- [ ] Finalize top-level README so a stranger can understand the project in under a minute
- [ ] Identify the right recipient — hiring manager for the Image PM role, or a warm-ish contact — not an unsolicited CTO cold email
- [ ] Draft a short outreach note (LinkedIn or email) that points to the repo and states the two gaps it closes

## Acceptance criteria
- README is outreach-ready (clear why/what/how, links to PRD, dashboard, walkthrough)
- Outreach note drafted and reviewed before sending
